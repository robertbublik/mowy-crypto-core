# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting form for this repository:

https://github.com/robertbublik/mowy-crypto-core/security/advisories/new

Do not open a public issue, discussion, or pull request containing exploit
details, secret material, or a meaningful recording. Use fabricated identifiers
and the smallest disposable fixture needed to explain the problem.

Please include the affected revision, platform and toolchain, preconditions,
reproduction steps, observed impact, and any proposed remediation. Expect an
acknowledgement within three business days and an initial triage disposition
within seven business days. These are response targets, not a promise that a
fix or public advisory will be available within that period.

## Supported versions

No production version exists. Until the first reviewed release, only the
current `main` revision is eligible for security fixes. Earlier commits,
development branches, generated artifacts outside a tagged release, and the
private application are not supported through this repository.

## Disclosure

Please allow time to reproduce and remediate a report before public disclosure.
The maintainer will coordinate an advisory and credit when appropriate. This
policy does not create a bug-bounty program or authorize testing against users,
hosted services, third-party systems, or non-disposable data.
