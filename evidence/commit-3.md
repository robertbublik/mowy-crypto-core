## Reviewable outcome

The native core now constructs the exact 115-byte
`MOWY-DEVICE-KEY-V1` signed input from canonical, non-nil network-order
UUIDs, unsigned big-endian timestamps, and one X25519 public key. The key
window is exactly 2,592,000 seconds. Ed25519 detached signing uses the
long-lived identity seed already held in the zeroizing 96-byte root item, and
verification rejects invalid structure, low-order X25519 inputs, bad
signatures, future windows, and expired windows before state mutation.

Rotation obtains fresh entropy through libsodium, constructs the new X25519
key through a fallible seeded API, and keeps both seed and private key in
zeroizing owners. The rotation API can return the public bundle only after a
protected-key-store implementation accepts the private key. An early rotation
or failed protected-store operation returns no publishable bundle. Rotation is
due at the exact end of the previous 30-day window. A prior private key remains
retained until the additional 604,800-second grace has ended and the count of
unconsumed sealed manifests is zero; timestamp overflow fails closed.

The public-only SQLite repository pins the first self-signed identity for one
account/device tuple, accepts an idempotent replay, accepts a newer signed
agreement key from the same identity, and blocks changed identities,
same-time equivocation, and rollback without changing the stored row. Its only
outward read re-verifies signature and validity. The table has exactly eight
public columns and fixed-length `BLOB` checks; unsigned timestamps are stored
as 8-byte big-endian blobs rather than lossy signed SQLite integers. It uses
bundled SQLite 3.53.2 with foreign keys on, `DELETE` journaling, `FULL`
synchronous writes, `secure_delete=ON`, in-memory temporary storage,
`trusted_schema=OFF`, one explicit immediate writer, and no dynamic-extension
feature.

This pin is deliberately fixture-local trust on first use. A self-signature
proves continuity only after the local pin exists; it does not bind a device
identity to an authenticated account or person. P3 human verification remains
mandatory before that stronger claim.

## Public deterministic vector

`vectors/device-key-bundle-v1.txt` contains only a fabricated disposable
identity and agreement seed. It freezes the identity public key, agreement
public key, all three UUID fields, both big-endian timestamps, the complete
115-byte signed input, and the 64-byte Ed25519 signature. Its SHA-256 is
`c8840c66468ab87d4ca76396762da383d53c83db9e80fbd4ebb671197ef2f015`.
The unit test derives both keypairs from the committed fixture seeds and
requires byte-for-byte equality with the vector.
