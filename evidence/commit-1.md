# Commit 1 build-boundary evidence

Status: Implemented and locally validated for P2 commit 1; no product or
cryptographic operation is exposed.

- Package: P2 sealed envelope foundation
- Requirements: `M2-ASSURANCE-01`
- Baseline: merged public-core revision `d9c2b07`
- Application gate evidence: `mowy` revision `4c8d4c8`
- Recorded: 2026-08-19

## Reviewable outcome

The public repository pins Rust 1.97.1 and the exact D26 dependency versions,
commits Cargo lock version 4 and all 152 external source directories, generates
Swift and Kotlin from a project-owned UniFFI interface, and exposes only
`core_profile_version()`. That function accepts no input and carries no secret,
plaintext, path, identifier, or cryptographic operation.

The default iOS normal dependency graph contains the six approved runtime
packages and excludes the binding generator and `proptest`. The generator is
behind the non-default `binding-generator` feature. Release profiles abort on
panic; authored code denies `unwrap`, `expect`, panic macros, debug macros, and
stdout/stderr formatting. UniFFI's required `no_mangle` exports are isolated in
one generated module while authored code remains under the deny-level unsafe
lint.

## Exact validation

The complete `scripts/check.sh` gate passed on macOS 26.3 with Cargo and rustc
1.97.1, Xcode 26.3, and Android NDK 27.1.12297006:

- `cargo fmt --all -- --check`: passed;
- `cargo clippy --locked --offline --all-targets --all-features -- -D warnings`:
  passed with no warnings;
- `cargo test --locked --offline --all-targets`: one bootstrap test passed;
- release library builds passed for `aarch64-apple-ios` (44.43 s),
  `aarch64-apple-ios-sim` (26.71 s), `aarch64-linux-android` (26.52 s), and
  `x86_64-linux-android` (26.85 s);
- the two Apple targets used Xcode clang; Android used NDK r27b API-24 clang;
- Swift and Kotlin regeneration was byte-identical to `bindings/generated`;
- the 22-entry build-script inventory matched the vendor tree;
- the CycloneDX 1.5 SBOM regenerated byte for byte with 131 shipped/build
  components, no missing licence expression, and a checkout-independent root
  reference;
- `cargo-deny 0.20.2` reported `advisories ok, bans ok, licenses ok, sources
  ok` against the 153-package lock graph;
- the exact libsodium archive and minisign hashes passed, and independent
  `rsign 0.6.6` verification reported both signature layers valid;
- a fresh host target directory built and tested in 46.50 s under macOS
  `sandbox-exec` with `deny network*`, in addition to Cargo offline mode;
- `git diff --check` is required immediately before commit; byte-exact Cargo
  vendor sources are excluded because their upstream whitespace is protected
  by Cargo checksums.

Four-target validation explicitly bound Cargo, rustc, and rustdoc to the same
rustup 1.97.1 sysroot. Without that binding, the host's separate Homebrew
1.97.1 `rustc` was selected and truthfully failed because that installation did
not contain the four rustup targets. `scripts/build-mobile.sh` preserves this
workaround through its `MOWY_CARGO_BIN`, `MOWY_RUSTC_BIN`, and
`MOWY_RUSTDOC_BIN` inputs.

## Boundary and remaining limits

This evidence proves only the reproducible public build boundary. It does not
prove key generation/storage, database state, byte formats, sealing, envelope,
archive, bridge secrecy, mobile lifecycle behavior, real recordings, or
independent assurance. Those remain in later P2 commits and the human-review
gate.
